# P60: Use an IMM for a Maneuvering Target

**Phase 6: Radar Tracking and Data Association**  
**Status:** Implemented by batch `P60`

## Guiding question

How can a tracker adapt when the target alternates between straight motion and maneuvers?

## Experiment

Simulate a trajectory with constant-velocity segments and acceleration bursts.
Noisy Cartesian position reports are generated by private seeded arithmetic.
The truth acceleration schedule is retained only for scoring and plots; neither
tracker receives it.

## Procedure

Run separate straight-motion and persistent-acceleration Kalman filters. At
every scan, explicitly mix their prior states and covariances, update both with
the same report, convert innovation likelihoods into model probabilities, and
combine their conditioned estimates. Plot model probabilities and state error,
then compare with one poorly matched fixed straight-motion model.

Two one-variable sweeps change maneuver acceleration and mode persistence. The
intentionally broken case gives the maneuver mode zero initial and transition
support, so it can never earn probability. Recovery restores positive support
and reruns the exact same report array.

## What this should teach

IMM tracking handles uncertain motion by blending model-conditioned estimates
and updating model likelihoods from innovations. A model probability is
evidence-weighted confidence in a motion explanation, not a sensor measurement
of the target's intent.

## Completion condition

Model probability rises during the matching motion regime and overall error
improves over a single poorly matched model. On the reviewed record, the mean
maneuver-model probability is higher during acceleration bursts than during
straight segments, and the IMM has lower overall and maneuver-scan position
RMSE than the fixed straight model.

## Dependencies and compatibility

The contractual prerequisite is implemented P59. Conceptually, P55 supplies
the Kalman prediction/innovation/correction foundation; P59 reinforces that
truth is for audit rather than association. This lesson needs Base MATLAB
R2016b or later because it is a script with local functions. It uses no
tracking, sensor-fusion, statistics, or parallel-computing toolbox and does not
call an opaque IMM or tracker object.
