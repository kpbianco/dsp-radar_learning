## Deterministic simulated-oracle results

The independent oracle in `tests/test_p65_module.py` uses Python standard
library complex arithmetic. It reproduces the Park–Miller generator, MATLAB
column-major noise layout, covariance, pivoted complex linear solve, weight
normalization, and separated output powers without importing or executing
`experiment.m`.

- Seed fixture: seed 6501 begins with uniforms
  `[0.0508792265555259, 0.127160718723741, 0.190199589911010,
  0.684507634343816]`; four indexed noise values bind the MATLAB reshape
  convention.
- Baseline conventional: desired response `0 dB`, interferer response
  `-18.5504729294 dB`, white-noise gain `9.0308998699 dB`, and output SINR
  `-9.5707724632 dB`.
- Baseline loaded MVDR: exact unit desired response within numerical tolerance,
  interferer response `-51.9515831591 dB`, white-noise gain
  `8.9280869037 dB`, output SINR `5.8601612267 dB`, and physical diagonal
  loading power `3.1978954799` for `alpha=0.01`.
- Snapshot-prefix output SINR for `[4,8,16,32,64,128,256]` snapshots is
  `[4.9351231377, 5.2783709687, 5.5325704982, 5.3085669725,
  5.7506414232, 5.8601612267, 5.9074057185] dB`. The finite-record dip at 32
  snapshots is retained to prevent a false universal monotonicity claim.
- Under the fixed 3-degree mismatch, loading `[1e-6,1e-4,1e-3,1e-2,1e-1,1]`
  gives output SINR `[-5.5698872965,-4.4019116901,-1.0723287344,
  3.5904269718,5.2165556644,2.1779558985] dB`. True-direction response rises
  from `-3.6075121484` to `-0.5917348993 dB` by `alpha=0.1`, while excessive
  loading weakens adaptive rejection.
- The four-snapshot covariance has rank 4 for 8 elements. Its two-norm
  reciprocal condition estimate is `6.81e-18`; the `alpha=0.1` loaded matrix
  estimate is `0.01238`. On the same data, tiny-load/mismatched SINR is
  `-4.6890683556 dB`, loaded/mismatched SINR is `5.2165327518 dB`, and
  loaded/corrected-look SINR is `5.8432130558 dB` with restored unit desired
  response.

These are simulated numerical results. They are not MATLAB-runtime,
rendered-figure, antenna, bench, field, or operational evidence.
