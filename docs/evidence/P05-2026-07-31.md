## Implementation and expected output inventory

`experiment.m` is one finite, sectioned base-MATLAB script. These eight figure
groups are source-reviewed expectations, not rendered evidence:

1. Equal-RMS short time records for Gaussian white, low-pass colored,
   co-channel narrowband, and impulsive disturbances.
2. Four distributions on common voltage-bin edges, including counts outside
   the displayed histogram range.
3. Manually accumulated normalized autocorrelation through 96 samples of lag.
4. Raw rectangular-window one-sided PSDs from DC through the 2048 Hz Nyquist
   frequency.
5. The same `0.18 V` peak, `512 Hz` target tone under every equal-RMS
   disturbance, with target-bin marker and coherent phasor error.
6. `alpha = [0, 0.70, 0.95]` colored-memory PSD and metric sweep using the same
   Gaussian driver and same RMS.
7. `[0, 16, 128] Hz` narrowband-offset sweep with target phasor error.
8. Broken raw-generator comparison exposing unequal RMS and the resulting
   confounded target-error ranking.

Axes and printed metrics use seconds, samples, hertz, samples/second, volts,
volts RMS, `V^2/Hz`, `dB V^2/Hz`, dB, radians, counts, correlation, crest
factor, and unitless power fractions. Named metrics include seed, record and
sample rate, target frequency/amplitude, common time-domain SNR, mean, RMS,
crest factor, impulsive-event count, lag-one correlation, fraction of power
below 200 Hz, coherent tone phasor error, sweep metrics, and broken-case raw
RMS ratio.

The script retains metrics in a workspace `results` structure and creates or
replaces its named working variables. It does not wholesale-clear the current
workspace or command window, change the global random stream, close unrelated
figures, write a file, update `.learning`, access a network or device, or start
an asynchronous task. On rerun it closes only figures carrying the P05-specific
tag.

## Independent numerical contracts

The focused Python test implements independent host-language versions of the
documented centering/RMS normalization, one-pole recursion, lag-one
correlation, direct DFT one-sided PSD, and coherent target projection. These
checks are not MATLAB-seeded runtime substitutes.

- Four deliberately different host-generated records all center to numerical
  zero and normalize to exactly `0.25 V RMS` within double-precision test
  tolerance; a constant zero-RMS record is rejected.
- A `64`-sample, `64 samples/s`, `8 Hz` coherent sinusoid at `0.25 V RMS`
  integrates from its independent one-sided PSD to `0.0625 V^2`; all power is
  in the expected positive-frequency bin within numerical tolerance.
- With a `0.25 V RMS` coherent sinusoidal interferer, the independent
  zero-offset target phasor error is
  `sqrt(2)*0.25 = 0.3535533905932738 V`. Integer-bin offsets of `16 Hz` and
  `128 Hz` produce error below `1e-13 V` in the direct projection model.
- The common baseline time-domain tone/noise ratio computed from a `0.18 V`
  peak tone and `0.25 V RMS` noise is `-5.863650028014443 dB`.
- The independent one-pole realization has near-zero lag-one correlation for
  `alpha=0`, greater than `0.65` for `alpha=0.70`, and greater than `0.93` for
  `alpha=0.95`. The host model also verifies the one-pole DC/Nyquist power
  ratio grows with `alpha`.
- A sparse independent impulsive record retains a crest factor greater than
  five after equal-RMS normalization and exceeds the white record's crest
  factor.

## Independent review and repairs

- The final system-risk review found that P05 began with `clear; close all;
  clc;` and seeded MATLAB's global RNG. Running the lesson could erase
  unrelated base-workspace variables and command-window context, close
  unrelated figures, and change the random sequence seen by later work. That
  contradicted the unqualified no-persistent-mutation claim. P05 now avoids
  wholesale workspace/command clearing, uses a private seeded `RandStream`,
  tags all eight of its figures, and closes only earlier P05-tagged figures on
  rerun. README, walkthrough, checks, source guards, and evidence now state the
  narrower file/learner-state rollback boundary and acknowledge that named
  script variables are still created or replaced.
- The manifest change newly enables the public `complete P05` state transition,
  but the CLI suite exercised completion only for P01. The added behavioral
  test runs `complete 5 --note ...` in an isolated fixture and verifies the
  persisted `current`, ordered `completed` list, and P05 note.
- The independent review found that `max_samples` and `max_sweep_cases` were
  visible constants but were not themselves protected from edits. A learner
  could set an infinite or very large ceiling and bypass the allocation bound.
  The experiment now validates fixed finite integer ceilings of 16,384 samples
  and eight sweep cases, plus exactly four canonical baseline types, before
  record allocation. Focused tests retain those guards and their ordering.
- Local inspection found the colored-memory assertion originally required
  every lag-one correlation increase to exceed `0.30`. The theoretical change
  from `alpha=0.70` to `0.95` is about `0.25`, so that assertion could reject a
  correct runtime. The threshold is now `0.15`, while still requiring a clear
  monotonic change. The independent host model verifies larger changes than
  the retained bound.
- The baseline random impulsive mask now explicitly includes sample 64 so the
  short-time panel always contains an outlier while the rest of the outliers
  remain seeded and sparse.
- After those repairs, the independent reviewer found no remaining actionable
  core numerical, physical, base-MATLAB, scope, or acceptance defect. The
  reviewer explicitly retained MATLAB absence as a validation boundary rather
  than treating Python models or source guards as runtime evidence.
