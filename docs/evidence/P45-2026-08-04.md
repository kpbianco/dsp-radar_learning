## Physical model and independent static oracle

For independent zero-mean Gaussian I/Q noise, each square-law power cell is
exponential with local mean `mu[k]`. With `T=12` training cells on each side,
`G=2` guards on each side, and `N=2T=24` total references, the implementation
uses

`p_hat[k] = sum(training powers)/N`,

`alpha = N*(Pfa^(-1/N)-1)`, and

`detect[k] = z[k] > alpha*p_hat[k]`.

The leading and lagging reference indices exclude the CUT and every guard.
Only cells 15 through 242 (MATLAB indexing) are eligible; the first and last 14
CUTs retain NaN estimates/thresholds and false decisions. For IID homogeneous
exponential CUT/reference cells,
`P(CUT > alpha*p_hat) = (1+alpha/N)^(-N) = Pfa`. The slowly varying single
profile is only a local-adaptation illustration, not a `Pfa` measurement.

`tests/test_p45_module.py` implements an independent standard-library Python
oracle. It checks the finite-`N` formula, exact reference indices and edge
policy, threshold/detection replay, local adaptation between two power regions
in one profile, monotonic requested-`Pfa` behavior, exact uniform-scale
threshold proportionality and decision invariance, arithmetic-mean versus
geometric-mean ordering, and recomputed recovery. This simulated oracle checks
the stated mathematical model; it is not MATLAB runtime or radar-system
evidence.

## Residual risks and unperformed validation

- MATLAB syntax, graphics behavior, assertions, memory use, figure rendering,
  and numeric results were not executed in MATLAB or a compatible runtime.
- The Python oracle uses the same documented distributions and equations but a
  different random-number implementation; it verifies invariants and expected
  behavior, not sample-for-sample MATLAB output.
- A slowly varying mean only approximates local homogeneity, and one 256-cell
  profile cannot validate rare false-alarm probability. P52 owns statistical
  CA-CFAR `Pfa` validation over many independent trials.
- The finite-`N` scale factor assumes independent exponential power cells. It
  excludes correlated samples, clutter edges, interfering targets, matched-
  filter sidelobes, quantization, receiver nonlinearity, and nonhomogeneous or
  nonstationary operational backgrounds.
- The uniform-scale sweep preserves decisions because it scales the entire
  scene, including targets and references. It does not claim invariance when
  target-to-background ratio or distribution changes.
- Point targets make guard separation structurally visible but do not model a
  finite matched-filter mainlobe; P46 varies guards/training cells and exposes
  contamination behavior.
- Educational effectiveness and personal completion require human figure
  observation and teach-back; repository tests do not establish them.
