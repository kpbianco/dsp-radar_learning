## Independent audits and repairs

The initial bounded risk review found four issues:

1. A P16 test froze the shared README frontier at P16. That assertion was
   removed; only shared manifest-derived tests own the moving frontier.
2. The broken-case frequency gate initially checked only phase sample `n`, even
   though the estimate uses `n-1` and `n`. The implementation and independent
   test now require both endpoint magnitudes and explicitly reject a threshold-
   exit interval.
3. Concatenating scalar controls before `islogical` could coerce a malformed
   logical value to numeric. Each frequency/notch/noise/threshold scalar now has
   a direct nonlogical numeric guard before concatenation, with source checks.
4. `yline` narrowed compatibility relative to retained repository policy. It was
   replaced with an ordinary two-point `plot`, and P16 compatibility checks now
   reject both `xline` and `yline`.

test proved that a threshold exit existed and source-checked the two-endpoint
expression, but did not behaviorally assert that the exit interval became
unavailable. `test_phase_difference_gate_behavior_rejects_both_low_amplitude_transitions`
now uses a deterministic magnitude sequence with a notch entry, notch exit, and
recovered interval. It asserts the exact reliability mask and `NaN`/finite
outputs, so a current-endpoint-only regression fails the test.
