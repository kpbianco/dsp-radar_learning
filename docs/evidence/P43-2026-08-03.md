## Physical model and independent static oracle

The experiment uses a real signed statistic with known positive target polarity:

```text
H0: x = n
H1: x = A + n
n ~ N(0, sigma^2)
decide H1 when x > gamma
P_FA = Q(gamma/sigma)
P_D  = Q((gamma-A)/sigma)
```

The baseline sets reference RMS to 1 amplitude unit, target amplitude to 4,
and design `P_FA` to 0.01. The implied threshold is
`gamma = 2.3263478740` amplitude units. A Python standard-library oracle used
its own seeded Gaussian generator; it did not execute, parse, or translate the
MATLAB script and does not claim MATLAB sample identity.

- Noise-RMS ratios: `[0.75, 1.00, 1.25, 1.50, 2.00]`.
- Empirical oracle `P_FA`: `[0.00090, 0.01045, 0.03215, 0.06280, 0.12240]`.
- Analytic `P_FA`: `[0.000962, 0.010000, 0.031367, 0.060463, 0.122379]`.
- Empirical oracle `P_D`: `[0.98745, 0.95435, 0.91015, 0.86925, 0.79885]`.
- Analytic `P_D`: `[0.987177, 0.952901, 0.909702, 0.867739, 0.798655]`.
- Positive-pedestal empirical `P_FA`:
  `[0.01045, 0.03490, 0.09310, 0.20465, 0.37250]`.
- Positive-pedestal empirical `P_D`:
  `[0.95435, 0.98520, 0.99680, 0.99940, 0.99995]`.
- Hidden case-RMS normalization held oracle `P_FA` exactly at `0.01045` for
  all five cases, demonstrating adaptation rather than a fixed native-unit
  threshold.
- Independently recomputed native-unit decisions exactly equaled the original
  fixed-threshold decision tuples.

Common standardized draws make the fixed-threshold H0 crossing sets nested as
RMS rises and H1 crossing sets nested in the opposite direction because this
lesson chooses `A > gamma`. The oracle confirms the model, monotonic
directions, analytic tolerances, hidden-adaptation mechanism, and recovery. It
does not prove MATLAB syntax, private-stream samples, figures, or pedagogy.

## Figure and metric inventory

1. **Fixed-threshold range profile:** range-cell index versus signed detector
   amplitude in amplitude units; fixed line, four truth markers, and threshold
   crossings distinguish individual false alarms, detections, and misses.
2. **Conditioned baseline distributions:** empirical probability per histogram
   bin versus signed amplitude for separate H0 and H1 banks; threshold is in
   amplitude units.
3. **Noise-RMS sweep:** empirical/model `P_FA` and `P_miss` versus RMS divided
   by reference RMS. Threshold, target, standardized draws, and trial count are
   fixed.
4. **Clutter-pedestal sweep:** empirical/model `P_FA` and missed-target count
   versus positive pedestal divided by reference RMS. Noise spread, target,
   threshold, and draws are fixed.
5. **Broken adaptation and recovery:** `P_FA` versus noise-RMS ratio for native
   fixed decisions, invalid oracle-normalized decisions, and recovered native
   fixed decisions.

Retained `results` include the seed, statistic convention, dimensions,
threshold calibration, range-profile conditioned counts, baseline empirical
and analytic probabilities, both sweep ratios/counts/probabilities, broken
claim marker, adaptive curve, exact recovery flag, recovered curve, and
resource ceilings. Fixed ceilings are 25,000 trials, 512 range cells, eight
targets, nine cases per sweep, five figure groups, and 800,000 conservatively
estimated stored numeric values. The estimator explicitly includes the
trial-by-noise-case decision matrix and deliberately counts overwritten loop
temporaries as simultaneously live; the maximum permitted configuration is
below the ceiling. Canonical controls are validated before
random draws, allocation, cleanup beyond P43-tagged figures, or plotting.

detection probability to respond to the shift, and rejects a mutation that
removes the H1 pedestal. The production MATLAB source was already correct and
needed no repair.
