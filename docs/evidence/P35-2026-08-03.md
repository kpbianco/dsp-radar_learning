## Physical model and independent static oracle

The script exposes the governing operations:

```text
PRI = 1 / PRF
R_u = c / (2 PRF)
q = floor(R_true / R_u)
R_app = R_true - q R_u = mod(R_true, R_u)
```

Independent Python with `c=299792458 m/s`, `PRF=20 kHz`, `R_true=18 km`,
and `Fs=20 MHz` produced:

- PRI `50.000000000000 us`
- unambiguous range `7494.811450000000 m`
- round-trip delay `120.083074271335 us`
- ambiguity order `2`
- apparent delay `20.083074271335 us`

- nearest display delay sample `2402`
- sampled marker `3012.914202900000 m`

  half-sample bound.
