## Physical model and independent static oracle

The model is the signed, known-positive-polarity convention continued from P43:

`H0: u ~ N(0,1)`, `H1: u ~ N(d',1)`, `d' = sqrt(10^(SNR_dB/10))`.

A detection is `u > gamma`, so `Pfa = Q(gamma)` and
`Pd = Q(gamma-d')`. False-alarm counts use only H0 trials; detection and miss
counts use only H1 trials. The marked `Pfa = 0.001` threshold is approximately
3.090232306 noise RMS, and its design expectation across 1,000,000
target-absent cells is 1,000 false alarms per scan.

`tests/test_p44_module.py` implements an independent Python standard-library
oracle with separate seeded Gaussian H0/H1 arrays. It checks non-increasing
empirical `Pfa` and `Pd` with threshold, increasing `Pd` with SNR at a fixed
threshold, analytic agreement within the reviewed absolute tolerance, finite
trial resolution, held-out failure after quiet-bank cherry-picking, and exact
replay.
This simulated oracle checks the stated mathematical model; it is not MATLAB
runtime or radar-system evidence.
