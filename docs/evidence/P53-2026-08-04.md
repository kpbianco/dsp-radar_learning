## Static behavioral evidence

The retained detector-to-report model is

```text
d(i,j) = CUT power(i,j) / threshold(i,j)
D(i,j) = d(i,j) > 1
w(i,j) = (d(i,j) - 1)^p
range_hat = sum_C(w range) / sum_C(w)
velocity_hat = sum_C(w velocity) / sum_C(w)
```

The independent Python oracles use small handcrafted matrices rather than
claiming MATLAB random-stream equivalence. They verify deterministic row-major
plateau ties, edge peaks, diagonal 8-connectivity, separated blobs, singleton
filtering, an end-to-end peak-only failure and grouped-report recovery,
geometric and excess-weighted centroids, translation, effective cell counts,
positive shape proxies, and rejection of malformed masks, axes, controls,
nonfinite values, and degenerate inputs. The end-to-end handcrafted scene has
11 threshold cells and four local maxima; minimum component sizes `[1 3 5]`
produce report counts `[4 2 0]`, so the baseline three-cell policy retains one
four-cell report for each extended target while rejecting the nuisance peaks.

The synthetic script background is seeded and normalized into score ratio
`[0.25, 0.45]`, so background alone cannot detect. Two analytic target blobs,
one asymmetric shoulder, two disconnected two-cell sidelobes, and three
isolated false cells supply the controlled crossings. The reviewed source
asserts that grouping recovers two target reports, the peak-only path emits
more reports, and truth errors remain within one range and velocity bin. Those
are inspected source contracts, not MATLAB measurements.
