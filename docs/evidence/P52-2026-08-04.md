## Static validation and behavioral evidence

The exact finite-training homogeneous model retained by the source and Python
oracle is

```text
Pfa(alpha,N) = (1 + alpha/N)^(-N)
alpha(N,Pfa) = N * (Pfa^(-1/N) - 1)
```

At `N=24` and requested `Pfa=1e-3`, finite-N alpha is approximately
`8.0045143719`. The intentionally broken `-log(Pfa)` multiplier is
`6.9077552790` and has exact finite-N Pfa `0.0023091420`, more than twice the
request. These are analytic/source-contract results, not MATLAB measurements.

The focused independent Python mismatch oracle uses 20,000 target-absent trials
and the same `N`, requested Pfa, correlation `0.65`, and log-texture standard
deviation `0.90`. Its test asserts broad mechanism-level facts: iid exponential
power stays within finite rare-event sampling tolerance, shared-component
correlation is conservative in this construction, and independent lognormal
texture overspends by more than eight times. It does not claim MATLAB
sample-for-sample equivalence or characterize measured clutter.

## Independent audit and repairs

Two bounded read-only audits examined statistical/MATLAB behavior and governed
contract durability. The principal agent remained the integration owner; no
subagent edited the workspace.

The statistical audit found that the walkthrough's lighter-texture edit and
reduced-trial timeout path could trigger empirical assertions intended only for
the reviewed canonical run. The repair defines a predicate containing the
reviewed trial count, `N`, requested Pfa, correlation, and texture controls;
empirical direction thresholds run only under that predicate, while analytic
miscalibration and recovery checks remain unconditional. The walkthrough now
identifies trial count, final running checkpoint, and block divisor as linked
bookkeeping controls. It also found that vector orientation was implicit; all
three sweep/checkpoint vectors now require row shape before arithmetic.

The contract audit found an indirect P52-specific assertion that froze the
moving root README frontier. That assertion was removed; only the shared
manifest-derived curriculum test owns the frontier. It also found a coupled
resource case where `running_alarm_count` remained live into the mismatch
allocation phase; the vector is now cleared immediately after retained running
metrics are formed, and the source binding prevents regression.

A subsequent independent system-risk review found that the accepted
`confidence_z_score` range allowed a valid learner edit to change interval
width while every plot and console line continued to claim 95%. The repair
derives the displayed confidence percentage from the selected z-score with
base MATLAB `erf`, retains the default as 95.0%, and adds a behavioral test
showing that 1.0-, 1.96-, and 3.0-sigma intervals widen and relabel together.
The reviewed-run predicate now also includes the canonical block size because
block reshaping affects deterministic random-value assignment. Focused,
contract, quick, and full checks were rerun after these final changes.
