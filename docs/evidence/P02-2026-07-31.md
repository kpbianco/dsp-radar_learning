## Implementation and retained outputs

`experiment.m` is one finite, sectioned script with these expected figures:

1. Dense 7 Hz reference and 80 samples/s measurements, plus the stored sequence
   versus integer sample index.
2. Explicit piecewise-linear interpolation versus the unobserved synthetic
   reference and stored samples.
3. Sample-rate panels at 80, 16, and 12 samples/s, with samples/cycle and
   Nyquist frequency in hertz.
4. Measurement-clock offsets of 0, 0.25, and 0.50 sample at 16 samples/s.
5. The 5, 7, and 19 Hz continuous candidates crossing one shared 12 samples/s
   sequence.

Axes use seconds, samples, hertz-derived titles, and arbitrary amplitude units.
Printed/asserted metrics include seed, tone and alias frequencies, sample rates,
Nyquist limits, samples/cycle, point/sample counts, interpolation RMSE,
measurement equation error, alias sample-agreement errors, and the computed
roundoff tolerance.

The independent Python model recomputed the default rate-sweep interpolation
RMSE values as `0.019284`, `0.411372`, and `0.659829` a.u. It verified default
5/7/19 Hz sample agreement below `1e-12` a.u. and reproduced a valid bounded
1,900-sample case whose floating-point disagreement exceeds `1e-12`; the
scale-aware MATLAB tolerance remains above that roundoff while capped at
`1e-9 * max(1, abs(A))`.
