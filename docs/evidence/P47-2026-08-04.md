## Physical model and independent static oracle

For normalized circular complex noise `w` with `E|w|^2 = 1`, the H0 CUT power
is `z = |w|^2`. The known-noise detector uses

`eta = -log(Pfa)` and `detect = (z > eta)`.

For `N` total independent homogeneous reference powers, the implementation
forms

`p_hat = sum(|r_i|^2)/N`,

`alpha = N*(Pfa^(-1/N)-1)`, and

`detect = (z > alpha*p_hat)`.

At a named target `Pd`, loss is
`SNR_required,CFAR - SNR_required,known` in dB. Raw empirical curves remain
the visible measurements; an explicit nondecreasing envelope is retained only
for bracketed linear crossing interpolation, along with its maximum adjustment.

`tests/test_p47_module.py` supplies an independent standard-library Python
oracle with 30,000 seeded complex-noise trials and gamma-distributed arithmetic
reference means. It measures approximately 2.02, 0.97, 0.48, and 0.24 dB loss
for `N = [8 16 32 64]` at `Pfa = 1e-3`, `Pd = 0.8`, and approximately 0.63,
0.97, and 1.31 dB for `Pfa = [1e-2 1e-3 1e-4]` at `N = 16`. It also proves
the exact H0 calibration formula and the broken multiplier's theoretical
`Pfa = 0.0032077400266028754`. On those same trials, the broken detector's
apparent loss falls to approximately 0.11 dB from the calibrated 0.97 dB while
its empirical false-alarm rate rises to approximately 0.00333; exact
recalibration restores the original curve and loss. These are simulated
mathematical model checks, not MATLAB execution, sample-for-sample MATLAB
results, or radar-system evidence.
