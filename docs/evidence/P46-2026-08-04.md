## Physical model and independent static oracle

For CUT `k`, `T` training cells and `G` guards per side, the implementation uses
the reference offsets `-(G+T):-(G+1)` and `(G+1):(G+T)`. With `N=2T`, it forms

`p_hat[k] = sum(reference powers)/N`,

`alpha = N*(Pfa^(-1/N)-1)`, and

`detect[k] = z[k] > alpha*p_hat[k]`.

The strong target response is constructed explicitly as
`sin(pi*u)/(pi*u)` on integer range-cell offsets with its zero-offset limit set
to one. This is a finite illustrative matched-response shape, not a measured
antenna or receiver response.

`tests/test_p46_module.py` supplies an independent standard-library Python
oracle. It verifies exact reference indices and edge eligibility, finite-`N`
scale behavior, target self-masking with zero guards, decreasing target energy
in farther reference sets, increasing stencil span, deterministic locality
error across the known mean-background transition, contaminated-reference
masking with unchanged CUT power, and recovery after the contaminator moves
inside the excluded guard region. These are mathematical model checks, not
MATLAB execution or radar-system evidence.

  use, figure rendering, and numeric results were not executed in MATLAB or a
  compatible runtime.
