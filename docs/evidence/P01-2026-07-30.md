   at 8 samples/s.

runtime was available.

### Printed/asserted metrics

- random seed (unitless integer);
- baseline sample count (samples);
- samples per cycle (samples/cycle);
- cycles in the one-second record (cycles);
- initial phase (radians);
- positive and negative per-sample rotation angles (radians/sample);
- projection and radius errors (arbitrary amplitude units);
- broken-case sample rate (samples/s);
- Nyquist limit, true frequency, and apparent frequency (hertz);
- true/alias sample agreement error (arbitrary amplitude units).

The script fails fast for malformed edited baseline or broken-case controls, a
non-integer, too-short, or over-5000-sample record, a baseline at or below the
strict Nyquist rate, a broken case that is no longer below Nyquist, failed
projection or radius invariants, or failed true/alias sample agreement.

  Those values intentionally fail the broken-case guard because they are above
  the 5 Hz tone's Nyquist threshold; the earlier wording presented them as
  ordinary whole-section observations and did not explain the expected stop.

  strict Nyquist boundary, the accepted and rejected resource-boundary cases,

  after review found that valid near-Nyquist controls could otherwise index a
  missing second sample.

  integer-count, and 5000-sample guards; and covered malformed values.
- Preserved the original phase when an edited tone aliases exactly to 0 Hz,
  where `sign(0)*phi` had incorrectly erased the constant sample value.
- Replaced hard-coded broken-case legend values with labels derived from the
  visible controls.
- Added explicit real-valued guards for amplitude, frequency, sample rates, and
  duration before relational arithmetic. Complex learner edits now fail with
  the documented control assertion rather than a MATLAB relational-operator
