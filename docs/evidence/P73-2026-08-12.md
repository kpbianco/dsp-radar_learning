## Deterministic simulated-oracle results

The permanent Python standard-library oracle mirrors the reviewed
Park-Miller/Box-Muller generator, MATLAB column-major noise layout, position
sums, dechirped steering, Hermitian scan, same-TX lag-one Doppler estimate, and
slot compensation.

For `c = 3e8 m/s`, `f_c = 77 GHz`, `lambda = 3.896103896 mm`, four RX
positions `[0, 0.5, 1.0, 1.5] lambda`, and two TX positions `[0, 2] lambda`:

- all eight TX/RX sums are unique and equal
  `[0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5] lambda`;
- RX-only and virtual apertures are `1.5 lambda` and `3.5 lambda`;
- ideal `+18 deg` half-power widths are `27.795716 deg` and `13.474360 deg`;
- the seeded `20 dB`-SNR baseline estimates are `+18.1 deg` RX-only and
  `+18.0 deg` virtual; and
- the script's reviewed retained working-value count is 19,020, below the
  immutable 500,000-value ceiling.

For target separations `[8, 16, 28] deg`, receive-only midpoint dips are
`[0, 0, 0.438700] dB` and virtual midpoint dips are
`[0, 1.969559, 26.328333] dB`. The permanent `0.25 dB` reviewed criterion
classifies the receive-only cases `[merged, merged, resolved]` and the virtual
cases `[merged, resolved, resolved]`.

The noisy velocity oracle reuses seed 7401, the `+18 deg` target, 64 complete
two-slot cycles, `40 us` slot spacing, and one noise record. For velocities
`[-10, -5, 0, +5, +10] m/s`:

- true Dopplers are `[-5133.333, -2566.667, 0, +2566.667, +5133.333] Hz`;
- estimated Dopplers are approximately
  `[-5136.481, -2568.591, -0.311, +2566.607, +5132.258] Hz`;
- uncompensated angle peaks are `[13.3, 15.6, 18.0, 20.3, 22.8] deg`; and
- compensated peaks are `[18.0, 18.0, 18.0, 17.9, 18.1] deg`.

The permanent velocity-isolation regression reconstructs and removes the
velocity-dependent target from every sweep record, then compares the remaining
complex residuals to 14 decimal places. All five cases retain the same noise
record, and the test also binds the MATLAB sweep loop to constant seed 7401.

The `+10 m/s` broken case has true Doppler `+5.133333 kHz` and inter-TX
temporal phase `-1.290147 rad`. Compensation derives a new record from the
measured Doppler and known slot times while the original nested complex arrays
remain exactly unchanged. These are deterministic simulated numerical results,
not MATLAB runtime or rendered-figure results.

## Independent audit findings and repairs

A bounded read-only physics audit detected a sign-boundary risk before final
verification: P61's raw receive spatial phase cannot be mixed with P70's
negative dechirped slow-time phase. The implementation now consistently uses
`tx .* conj(rx)` negative spatial and temporal phase, and documents why P61's
raw snapshot has the opposite spatial sign.

A separate read-only implementation audit found that an early microphone
analogy called the `2 lambda` TX offset the receive-row length even though the
four-RX aperture is `1.5 lambda`. The lesson and walkthrough now state the
correct construction: four receiver spacings, placing the second virtual block
one half-wavelength sample after the first block. It also found that the
focused test allowed more than the immutable five figures and did not bind its
malformed-input mirror tightly enough to the MATLAB validator. The test now
requires exactly five P73 figure calls plus the visible validator invocation,
row-shape guard, Doppler-Nyquist guard, and resource-ceiling guard. Both audits
retained read-only scope; the principal agent owned all edits and integration.

The independent system-risk review found that the claimed one-variable
velocity sweep was not behaviorally protected against changing the MATLAB loop
to a per-case seed. Existing angle tolerances could still pass while each case
used a different noise realization, weakening the causal lesson. The focused
suite now verifies that removing the deterministic target leaves the same
complex noise residual in every velocity case and that the MATLAB loop uses one
constant seed. No experiment implementation change was necessary.

## Residual risks

- MATLAB was not installed, so syntax and behavior were assessed statically
  and with a durable independent oracle rather than the named runtime.
- Figures were not rendered or manually reviewed; plot legibility and MATLAB's
  exact graphics behavior remain runtime/manual-learning risks.
- The model begins at a selected FMCW range-bin sample. It does not reproduce
  P70-P72 fast-time range processing or test range-angle-Doppler association.
- The narrowband calibrated stop-and-hop model omits migration, acceleration,
  within-chirp coupling, multiple targets in one selected cell, leakage, phase
  noise, channel mismatch, coupling, element patterns, multipath, and ADC
  effects.
- Compensation depends on an unaliased, associated same-TX Doppler estimate
  and correct slot timing. Real multi-target data can violate both conditions.
- Static tests plus a separate numerical oracle reduce but cannot eliminate
  MATLAB-specific numeric, parser, or graphics risk.
