transition reused baseline receiver noise but changed modulation depth from
`0.60` to `0.80` at the same time as message content. A learner comparing the
new sideband amplitudes could therefore attribute depth-driven growth to the
message change, while this evidence incorrectly said the message was the only
changed input. Existing tests verified the `0.80` weighted sidebands and noise
reuse separately, but did not behaviorally prove a paired one-variable
transition.

The repair makes `multitone_modulation_depth` inherit the baseline `0.60` depth,
retains that shared control in `results`, and updates lesson/walkthrough wording
and expected sideband amplitudes. The added behavioral regression constructs
baseline and multitone records with one shared carrier, depth, and deterministic
noise vector, then proves their paired difference is exactly the changed message
contribution. It also binds the shared-depth and shared-noise behavior to the
MATLAB source and rejects a fresh multitone noise draw.
