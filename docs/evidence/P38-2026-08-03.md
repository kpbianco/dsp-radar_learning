## Physical model and independent static oracle

The script exposes the governing operations:

```text
lambda = c/f_c
f_d = 2 v/lambda
omega = 2 pi f_d/PRF
H2 = 1 - exp(-j omega)
H3 = (1 - exp(-j omega))^2
```

For white input noise, the coefficient-energy power gains are exactly
`1^2 + (-1)^2 = 2` and `1^2 + (-2)^2 + 1^2 = 6`. Independent Python using
`c=299792458 m/s`, `f_c=10 GHz`, and `PRF=5 kHz` produced wavelength
`0.0299792458 m`, unambiguous speed magnitude `37.47405725 m/s`, and blind-speed
spacing `74.9481145 m/s`.

The two baseline target cases were:

| Velocity (m/s) | Doppler (Hz) | Phase step (rad/pulse) | Two-pulse gain | Three-pulse gain | Two/three SNR change (dB) |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 3 | 200.138457 | 0.251501 | 0.250839 | 0.062920 | -15.022 / -31.806 |
| 15 | 1000.692286 | 1.257507 | 1.176274 | 1.383621 | -1.600 / -4.961 |

The independent complex-sequence oracle checked both difference equations at
velocities `-15`, `-3`, `0`, `3`, and `15 m/s`; measured RMS amplitude gains
matched `|H2|` and `|H3|` to 12 decimal places. Constant complex rows canceled
exactly in both filters. Dopplers at `m*PRF`, for `m=-2..2`, produced periodic
nulls. A private Python seed with 4096 circular-complex samples measured noise
power gains within test tolerances around the permanent theoretical values 2
and 6. Independently differencing the canonical clutter profile along range
left a `0.386893909275` RMS residual ratio, while the correct slow-time
difference was zero. The declared resource formula evaluates to 249,996 stored
numeric values, below its 1,000,000 ceiling. This host-language oracle is not
MATLAB execution.
