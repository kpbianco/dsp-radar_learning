## Implementation and retained output inventory

`experiment.m` is one finite, sectioned base-MATLAB script with these expected
figure groups. These are source-reviewed expectations, not rendered evidence:

1. Baseline voltage view: 0.9 V peak input and 6-bit `+/-1 V` ADC staircase,
   plus time-domain error bounded by half an LSB.
2. Baseline error spectrum: one-sided DFT magnitude in dBFS from DC through the
   2048 Hz Nyquist frequency.
3. Bit-depth sweep: 3-, 6-, 10-, and 14-bit staircases for the same signal and
   full-scale range.
4. Bit-depth metrics: RMS voltage error and measured signal/error ratio versus
   ADC bits.
5. Full-scale sweep: the same 0.9 V peak input through 8-bit ADC ranges of
   `+/-1 V`, `+/-3.6 V`, and `+/-9 V`, producing 90%, 25%, and 10% use.
6. Utilization metric: measured signal/error ratio versus percentage of ADC
   full-scale range used.
7. Dither comparison: undithered and seeded TPDF-dithered total error versus
   sample index and their one-sided spectra in dBFS.
8. Broken clipping case: 1.35 V input against a `+/-1 V` range, saturated
   waveform, full-scale boundaries, and clipping error.

Axes and printed metrics use seconds, samples, hertz, samples/second, volts,
volts RMS, volts/LSB, bits, levels, percent, dB, dBFS, radians, correlation,
and sample counts. Printed/asserted metrics include seed, tone/sample rate, ADC
range, bit depth, levels, LSB size, clipped samples, RMS and peak error,
measured SNR, ideal-SQNR reference, utilization loss, dither support,
signal/error correlation, and audio-preview preflight sizes.

Optional audio vectors concatenate original, quantized, clipped, and amplified
error segments. The script never calls an audio function. All gap and preview
sizes are derived and asserted before allocation; playback is an explicit
learner action and was not performed.

The independent utilization model held every 0.9 V input sample fixed while
widening the ADC range and measured `16.26355670675344 dB` loss from 90% to 10%
range use; the range-utilization reference is
`20*log10(0.9/0.1) = 19.084850188786497 dB`. The difference is retained rather
than hidden because the ideal quantization-noise approximation is not exact for
this coherent deterministic sine.

quantizer. Python's random generator is not MATLAB's `twister`, so these values

- largest one-sided DFT magnitude changed from `0.003941448969951711` to
