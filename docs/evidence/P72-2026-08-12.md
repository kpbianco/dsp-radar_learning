## Deterministic simulated-oracle results

The permanent Python standard-library oracle reproduces the two private
Park-Miller/Box-Muller streams, both 3,200-sample chirp legs, the 3,176-sample
valid overlap, explicit delayed/Doppler-shifted echoes, `tx * conj(rx)`, signed
lag-one phase estimates, and sum/difference solve.

For `f_c = 77 GHz`, `fs = 80 MHz`, `T = 40 us`, `B = 20 MHz`,
`S = 0.5 THz/s`, `R = 45 m`, and `v = +20 m/s`:

- delay is `0.300 us`; the first-order target travels `1.600 mm` over two
  idealized legs;
- delay contributes `150.000 kHz` and Doppler contributes
  `+10.266667 kHz`;
- ideal signed beats are `+139.733333 kHz` up and `-160.266667 kHz` down;
- seeded noisy estimates are `+139.736090 kHz` and `-160.252084 kHz`;
- the recovered delay beat is `149.994087 kHz` and recovered Doppler is
  `+10.257997 kHz`;
- recovered range is `44.998226 m`, error `-0.001774 m`; and
- recovered velocity is `+19.983110 m/s`, error `-0.016890 m/s`.

The noiseless oracle recovers range within `1.2e-12 m` and velocity within
`1.7e-11 m/s`. At noise RMS `0.002/0.01/0.03/0.08 V/V`, this fixed realization
produces range errors `-0.001774/-0.012516/-0.064923/-0.355981 m` and velocity
errors `-0.016890/-0.085965/-0.269298/-0.794798 m/s`. These are deterministic
simulated numerical results, not MATLAB runtime results.

For the two-target association scene, ideal signed up beats are
`+92.300/+221.800 kHz`; sorted down beats are
`-211.533333/-107.700 kHz`. Pairing both sorted lists creates ghost ranges
`45.575/49.425 m` with velocity magnitudes above `90 m/s`. Reversing only the
down-beat association on the unchanged lists recovers the `30/65 m` and
`+15/-10 m/s` truths. The script applies the same failure and recovery to
peaks extracted from composite seeded records.
