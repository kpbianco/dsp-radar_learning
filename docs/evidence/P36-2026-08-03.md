## Physical model and independent static oracle

The script exposes the governing operations:

```text
lambda = c / f_c
f_d = 2 v_r / lambda
Delta_phi = 2 pi f_d / PRF
v_r = lambda f_d / 2
```

The sign convention is positive radial velocity toward the radar. Independent
Python using `c=299792458 m/s`, `f_c=10 GHz`, `PRF=4 kHz`, `v_r=15 m/s`, and
`N=32` produced:

- wavelength `0.0299792458 m`;
- Doppler `1000.6922855944562 Hz`;
- phase increment `1.5718837664637613 rad/pulse`;
- unambiguous speed magnitude `29.9792458 m/s`;
- Doppler-bin spacing `125 Hz`; and
- velocity-bin spacing `1.8737028625 m/s`.

The independent complex-sample/DFT oracle also checked `-15`, `0`, and
`+15 m/s`: adjacent-product estimates retained signed Doppler within 20 Hz,
FFT peaks stayed within half a bin, and the magnitude-only broken sequence
reported zero Doppler.

The risk-review regression also constructs two noiseless slow-time sequences
whose physical Dopplers differ by exactly one PRF. Their 32 complex samples
agree within `1e-12`, and their centered DFT reports are identical, directly
checking the documented modulo-`2*pi` ambiguity instead of only rejecting an
out-of-interval control.
