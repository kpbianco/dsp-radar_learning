## Implementation and retained output inventory

`experiment.m` is one finite, sectioned base-MATLAB script with these expected
figure groups. These are source-reviewed expectations, not rendered evidence:

1. Baseline continuous-time view: 700 Hz input, 300 Hz apparent alias, and
   1000 samples/s stems on time in seconds and amplitude in arbitrary units;
   plus the stored sequence versus sample index.
2. Input-frequency sweep: theoretical and recurrence-estimated apparent
   frequency from 0 through 3000 Hz, and signed fold from -500 through +500 Hz.
3. Representative sequences: 450, 500, 550, 950, 1000, and 1050 Hz inputs
   around Nyquist and integer-sample-rate folds, versus sample index.
4. Sample-rate sweep: one 700 Hz input sampled at 2000, 1200, 1000, and 800
   samples/s, producing expected apparent frequencies 700, 500, 300, and
   100 Hz.
5. Broken case: the correct 300 Hz alias with phase `-phi`, the deliberately
   wrong 300 Hz model with phase `+phi`, the 700 Hz input, and sample stems.

Axes and printed metrics use seconds, samples, hertz, samples/second, radians,
and arbitrary amplitude units. Printed/asserted metrics include seed, input and
sample frequencies, Nyquist limit, alias order, signed fold, apparent and
estimated frequencies, estimator error, sample disagreement, sweep count and
range, correct/broken phase, and correct/broken model errors.
