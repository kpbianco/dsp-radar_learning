## Physical model and independent static oracle

The self-contained post-processing scene preserves P42's matrix convention:
96 range rows spaced 30 m and 64 signed radial-velocity columns spaced 0.625
m/s. Seeded exponential square-law background power increases with range and
contains a smooth zero-Doppler ridge. Three target centers are inside the
full-stencil region; a fourth intentionally occupies an excluded border. A
separable nine-by-nine target response makes range/Doppler spread and small
training-annulus sidelobe contamination visible.

For baseline half-widths `(Tr,Gr,Td,Gd)=(6,2,4,2)`, the explicit outer
rectangle is 17 by 13 and the guard+CUT rectangle is 5 by 5. Therefore

```text
N = 17*13 - 5*5 = 196
alpha = N*(Pfa^(-1/N)-1) = 7.030925258328118 at Pfa=1e-3
eligible CUTs = (96-16)*(64-12) = 4160
excluded border cells = 6144-4160 = 1984
```

An independent Python oracle uses its own seeded exponential samples, recreates
the physical mean/background and target-response equation, explicitly visits
the rectangular annulus, and applies the same square-law CA equation. It finds
all three interior target CUTs testable and detected, and the edge target
untestable and not detected. It produces 47 crossing cells total, including
spread target cells and permitted noise crossings; this is illustrative, not
an achieved-`Pfa` estimate. Multiplying the complete map by four multiplies
every eligible threshold by four and leaves the full decision mask exactly
unchanged.

The geometry oracle independently gives range-sweep training counts
`[118,196,352]` and valid shapes `[(86,52),(80,52),(68,52)]` for
`Tr=[3,6,12]`. It gives Doppler-sweep counts `[128,196,332]` and valid shapes
`[(80,56),(80,52),(80,44)]` for `Td=[2,4,8]`. These permanent facts prove that
one sweep changes only range coverage and the other only Doppler coverage.
They do not assert monotonic detection performance on one realization.

These are independent simulated mathematical checks, not MATLAB execution,
sample-for-sample MATLAB results, rare-event validation, measured-clutter
evidence, or a radar-system claim.
