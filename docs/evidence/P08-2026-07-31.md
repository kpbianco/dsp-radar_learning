## Independent numerical contracts

`tests/test_p08_module.py` independently implements reference normalization,
embedding, the relative-lag correlation sum, and full convolution in Python.
These checks do not substitute for MATLAB runtime evidence.

- The 13-chip asymmetric reference repeated twice becomes a 26-sample,
  zero-mean, unit-RMS reference with energy 26. Its reversal is different, so
  an accidental convolution/correlation orientation change is observable.
- A separate bounded deterministic noise sequence plus a `0.65 V` copy at
  delay 137 produces a correlation peak at lag 137. Every one of 281 explicit
  correlation values matches independent full convolution with the reversed
  reference to floating-point tolerance.
- A second signed two-record fixture verifies correlation superposition at
  every lag under unequal signed scale factors. A separate `-0.70 V` copy has
  its largest-magnitude correlation at the configured lag 43 with a negative
  `-18.2 V` value; the largest signed-positive value is deliberately elsewhere,
  so the test distinguishes signed correlation from an absolute-value or
  energy detector.
- With identical delay and noise samples, true-lag response differences equal
  amplitude change times reference energy. With identical clean signal and
  standard noise samples, the correlation noise residual scales linearly with
  the configured noise multiplier.
- In an independent noiseless two-copy model, one-sample separation has one
  local dominant peak rather than two; 8- and 32-sample separations have local
  peaks at both known delays.
- Treating the zero-based convolution-output index as delay produces the
  expected 25-sample offset. Indexing the explicit lag vector recovers zero
  delay error.
- Zoom-bound tests cover valid start delays 0, 5, 137, and the maximum
  sweep-compatible delay 198 in a 256-sample record with a 26-sample reference
  and maximum second-copy separation 32.
