## Physical model and independent static oracle

The source exposes

```text
n_k = round((2 R_k/c) f_s)
f_d,k = 2 v_k/lambda
X[n,p] = sum_k A_k g[n-n_k] exp(j(phi_k + 2 pi f_d,k p/PRF)) + w[n,p]
```

with fast-time/range samples in rows and slow-time pulse looks in columns.
Positive radial velocity means approaching. Independent Python using
`c=299792458 m/s`, `f_s=20 MHz`, `f_c=10 GHz`, `PRF=5 kHz`, and `32` pulses
produced:

- range-bin spacing `7.49481145 m`;
- target MATLAB rows `61`, `121`, and `161` for true ranges 450, 900, and
  1200 m;
- measured row ranges `449.688687`, `899.377374`, and `1199.169832 m`;
- Dopplers `0`, `+800.553828475565`, and `-1200.830742713348 Hz`; and
- phase increments `0`, `+1.006005610537`, and `-1.509008415805 rad/pulse`.

The independent nested-loop matrix oracle checked the `256 x 32` orientation,
local range-response maxima, per-row adjacent phase, range-sweep row motion,
velocity-sweep phase direction, magnitude-only phase loss, and exact recovery
of retained coherent samples. This is not MATLAB execution.

### Independent system-risk reviews and repairs

The implementation review found no high-severity issue and three repairable
risks:

1. baseline and sweep range bins were used to index the MATLAB range axis
   before their bounds assertions;
2. the evidence regression required command strings but could accept unfinished
   result prose; and
3. the reported recorded-range span used `N/f_s` although the plotted
   coordinate spans samples zero through `N-1`.

The repair moves both range bounds checks ahead of every affected index,
asserts this source order, requires an exit-zero result adjacent to every
mandated evidence command while rejecting unfinished-result language, and
reports the range-axis span as `(N-1)/f_s`. The same repair also makes the
stop-and-hop assumption measurable: the maximum omitted baseline motion is
`0.1116 m` (`0.0149` range bin), and source rejects half-bin or larger
migration. Focused P37 plus shared-curriculum tests then passed 16/16 before the
quick and full runs reported above.

A follow-up independent system-risk review found two additional bounded risks:

1. changing P37 to `implemented` exposed a public learner-CLI lifecycle path,
   but focused coverage exercised only explicit `learn start 37`; it did not
   prove that unqualified `learn start` selects P37 after P01-P36 completion or
   preserves prior completions and notes; and
2. two plot labels described raw reference-scaled amplitude as normalized and
   an ideal range response as a computed mean, so a learner could infer
   processing that the script did not perform.

The repair adds an isolated behavioral test that starts from completed P01-P36,
selects P37 through the unqualified CLI path, verifies persisted current,
completion, and note state, and proves repository `.learning/` bytes are
unchanged. It relabels the affected axes as `Relative magnitude` and `Ideal
relative magnitude`, and the source contract now retains both labels. Focused
P37 plus shared-curriculum tests passed 17/17 before the final quick and full
runs reported above.
