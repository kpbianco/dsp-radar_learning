## Independent oracle results

The standard-library Python oracle independently constructs the 400-sample
complex LFM, explicit cosine weights, zero-extended responses, first-minimum
PSLR, interpolated half-power crossings, white-noise weighting loss, isolated
leakage margin, and coherent two-target local-peak behavior.

- Rectangular (`alpha=0`): PSLR -13.547437 dB; full -3 dB width
  16.442479 m; output-SNR change 0 dB; baseline leakage margin -4.524474
  dB; no distinct clean weak-target local peak.
- Intermediate cosine (`alpha=0.5`): PSLR -21.005209 dB; width
  18.562018 m; output-SNR loss -0.235762 dB; margin -0.497018 dB.
- Hann-like (`alpha=1`): PSLR -31.484449 dB; width 26.942894 m;
  output-SNR loss -1.771784 dB; margin +13.141081 dB; a distinct clean
  weak-target local peak.
- Separation `[7 13 17 32]` sample rectangular margins are
  `[-14.411363 -9.706637 -4.524474 7.356751]` dB. Hann-like margins are
  `[-15.091536 5.791630 13.141081 21.765980]` dB.
- The seven-sample broken case gives negative margin for both filters, and the
  Hann-like clean two-target response has no distinct weak-target local peak;
  lower Hann-like PSLR cannot compensate for the weak target lying in the
  widened mainlobe. Restoring the 17-sample scene gives +13.141081 dB margin
  and a distinct clean weak-target local peak.
- Negative cases reject missing/empty/duplicate/malformed identity data,
  Boolean/wrong seeds, NaN/infinite/nonpositive controls, Nyquist violations,
  unordered/noninteger/out-of-range sweeps, too-short tapers, unapproved
  controls, baseline/broken separations outside the bounded scene, non-fitting
  echoes, and each represented resource-ceiling violation. Source mutations
  that substitute rectangular weights in the Hann, sweep, broken, or recovery
  paths are rejected.

The Python oracle does not reproduce MATLAB's `RandStream` sequence and makes
no claim about the exact MATLAB noisy trace.
