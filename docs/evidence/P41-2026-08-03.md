## Physical model and independent static oracle

The implemented background model is:

```text
w[p,r] ~ CN(0, noise_power), independent over pulse and range
u[p,r] = alpha*u[p,r-1] + sqrt(1-alpha^2)*e[p,r]
g[p,r] = beta*g[p-1,r] + sqrt(1-beta^2)*u[p,r]
P_c(R) = P_floor + P_near*(R/R_near)^(-eta)
c[p,r] = sqrt(P_c(R))*g[p,r]
```

With 96 bins from `0.25 km` through `5.00 km`, `P_near=25`,
`P_floor=0.10`, and `eta=2`, the independent oracle produced near/far
clutter powers `25.100000000000` and `0.162500000000 amplitude^2`, a ratio of
`154.461538461538`. The exact AR oracle preserves the innovations when
`alpha=0` and applies the documented `sqrt(1-alpha^2)` scale otherwise.

The target-power laws are:

```text
steady:       P = Pbar
Swerling I:   P = -Pbar*log(U), one draw held for the dwell
Swerling II:  P = -Pbar*log(U), independent draw per pulse
Swerling III: P = -(Pbar/2)*log(U1*U2), one draw held for the dwell
Swerling IV:  P = -(Pbar/2)*log(U1*U2), independent draw per pulse
amplitude = sqrt(P)
```

A deterministic 100,000-sample Python oracle using seed 4101 produced
normalized exponential power mean/variance `1.002915925651 / 1.014422057608`
and gamma-shape-two mean/variance `0.997191994226 / 0.496582645084`, close to
the theoretical `1 / 1` and `1 / 0.5` values. These are independent
host-language checks, not MATLAB results.

The clean dwell-power coefficient-of-variation limits are:

| Averaged pulses | Steady | Swerling I | Swerling II | Swerling III | Swerling IV |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 0 | 1 | 1 | 0.707107 | 0.707107 |
| 16 | 0 | 1 | 0.25 | 0.707107 | 0.176777 |
| 32 | 0 | 1 | 0.176777 | 0.707107 | 0.125 |

The added deterministic 2,000-dwell, 16-pulse noisy-statistic oracle produced
normalized input mean powers `0.501187`, `0.496363`, `0.502829`, `0.495315`,
and `0.503594` for steady/I/II/III/IV, respectively, around the common
`-3 dB` ensemble value `0.501187`. With one empirical noise-only threshold,
the corresponding target-present crossing rates were `0.5370`, `0.4395`,
`0.5280`, `0.4785`, and `0.5340`; the noise-only crossing rate was `0.0500`.
Repeating the oracle with seed 4101 returns the identical tuple. These values
are independent Python evidence and are not MATLAB runtime output or calibrated
probability-of-detection claims.

For the broken-case analytic oracle, the global background mean is
`2.476124928866 amplitude^2` and its nominal 5% exponential threshold is
`7.417807362755 amplitude^2`. Applying that one threshold across the profile
gives average near/far background crossing probabilities `0.303431636016` and
`0.001799850925`. Dividing by the known local mean makes the normalized
exponential crossing probability exactly 0.05. That is an oracle model check,
not estimated CFAR or calibrated operational detection evidence.
