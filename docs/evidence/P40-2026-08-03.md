## Physical model and independent static oracle

The implemented model is:

```text
x[n] = A exp(j(phi[n] + epsilon[n])) + w[n]
z_coherent = sum(x[n] exp(-j phi[n]))
T_coherent = |z_coherent|^2
T_noncoherent = sum(|x[n]|^2)
single_pulse_SNR = rho = A^2 / noise_power
stable coherent output SNR = N rho
coherent detectability d_c = N rho
noncoherent power detectability d_nc = sqrt(N) rho
Gaussian-jitter coherent gain = 1 + (N - 1) exp(-sigma_phi^2)
```

For input SNR `-8 dB` and `N=32`, the independent oracle produced `rho=0.158489319246`, stable coherent output SNR `5.071658215876` linear or `7.051499783199 dB`, coherent detectability `5.071658215876`, and noncoherent power-statistic detectability `0.896550979077`.
