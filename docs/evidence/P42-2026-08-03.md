## Physical model and independent static oracle

The implemented target model is

```text
x_q[r,p] = a_q s[r-d_q] exp(j phi_q + j 2 pi f_d,q p/PRF)
R_q = c d_q/(2 Fs)
f_d,q = 2 v_q/lambda
h[m] = conj(s[Ns-1-m])
y[r,p] = sum_m x[m,p] h[r-m]
Z[r,k] = sum_p w[p] y[r,p] exp(-j 2 pi k p/Np)
```

The standard-library oracle constructs an independent eight-sample complex
chirp, inserts targets at delays `(5, 5, 17)` and signed Doppler bins
`(-3, +4, +4)`, aligns them through explicit correlation, and evaluates a
direct DFT. It deterministically returns peaks `(5, 13)`, `(5, 4)`, and
`(17, 4)` in the unshifted 16-bin representation, each with magnitude exactly
`128`. Bin 13 is signed bin `-3`. Thus equal range/different Doppler and equal
Doppler/different range are both independently exercised.

The source-bound physical-coordinate oracle maps ranges `(1200, 1200, 2400) m`
to delay samples `(160, 160, 320)` and velocities `(-7.5, 10.3, 10.3) m/s` to
signed 64-pulse Doppler bins `(-8, +11, +11)`. Source guards additionally
require three distinct measured 2-D peak indices and every truth-associated
peak to exceed the deterministic full-map median by more than 20 dB.

A separate single-target oracle uses delay `5` and signed Doppler bin `+3`.
The correct slow-time DFT produces magnitude `128` in bin `+3`, with every
other bin at that range below `1.6e-13`. The deliberately wrong fast-time DFT
is finite and nonzero (`28408.2765` total squared magnitude), but its magnitude
spread across the 16 still-untransformed pulse columns is only `3.6e-15`;
there is no Doppler-bin concentration. Reapplying the slow-time DFT recovers
the correct complex map exactly in the independent oracle.

For the 64-sample fractional-bin window oracle at offset `10.10`, the
coherent-gain-normalized rectangular spectrum has one bin at or above -6 dB
and a fixed-guard sidelobe metric of `-29.218639136992 dB`; Hann has two such
bins and `-43.200024914697 dB`. This verifies the visible width/sidelobe
tradeoff. With the oracle's rounded `lambda=0.03 m`, pulse counts 16, 32, and
64 give CPI durations 4, 8, and 16 ms and velocity spacings 3.75, 1.875, and
0.9375 m/s.

The MATLAB source uses exact `c=299792458 m/s`: range sampling is about
`7.4948 m`, nominal `c/(2B)` range resolution is about `18.7370 m`, Doppler
spacing is `62.5 Hz`, and velocity spacing is about `0.93685 m/s`. These are
formula results, not MATLAB runtime measurements.
