## Deterministic simulated-oracle results

The independent Python oracle uses only the standard library and separately
implements the private Park–Miller/Box–Muller record, complex plane-wave
samples, principal phase, unwrapping, centered least-squares slope, adjacent
conjugate products, electrical-spacing sweeps, angle inference, and input
validation.

- Wavelength is `0.09993081933333334 m`; half-wavelength physical spacing is
  `0.04996540966666667 m`.
- Adjacent baseline propagation delay is `-83.33333333333333 ps` and ideal
  phase slope is `pi/2 = 1.5707963267948966 rad/element`.
- Seed 6101 begins with standard-normal values
  `(-2.4594363255591865, -0.1864958758150864, 0.05219237172820211, 0.3223791768106528)`.
- The noisy fitted slope is `1.5687500925676876 rad/element`, its inferred
  angle is `29.95691726617107 deg`, and its phase-fit RMSE is
  `0.014886743039711934 rad`.
- The clean angle sweep `[-60 -30 0 30 60] deg` produces monotonic odd-symmetric
  slopes and recovers every angle to numerical precision, including zero slope
  at broadside.
- A separate causal test starts from one-way geometric delays, samples the
  delayed analytic carrier without the snapshot helper, and recovers `-30`,
  `0`, and `+30 deg` with the expected delay and slope signs.
- Physical-spacing and fixed-spacing frequency paths both visit electrical
  spacing `[0.25 0.375 0.5] wavelengths` and slopes
  `[pi/4 3*pi/8 pi/2] rad/element`; only the physical-spacing path changes
  geometric delay.
- The one-wavelength broken snapshots differ by less than `1e-12`. The
  principal inverse reports `-23.578178478201835 deg` instead of the true
  `36.86989764584402 deg`; half-wavelength recovery returns the true angle to
  numerical precision.

These are simulated oracle results, not MATLAB runtime or physical-array
results.
